# tayhanagarcia.com · propuestas

Sitio estático (HTML, CSS y JS sin build) con dos propuestas de diseño para Tayhana García.

- `index.html`: selector de propuestas
- `propuesta-a.html`: A · Escenario (oscuro)
- `propuesta-b.html`: B · Luz editorial (claro)

## Publicar en GitHub Pages
1. Sube esta carpeta a un repositorio nuevo.
2. Settings > Pages > Deploy from a branch > `main` / root.
